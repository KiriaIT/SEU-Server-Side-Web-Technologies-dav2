# SEU-Server-Side-Web-Technologies-dav2

PHP-ით საქაღალდეებთან მუშაობა: 12 სავარჯიშო, სადაც POST მეთოდით საქაღალდეები და ფაილები იქმნება ან იშლება, GET მეთოდით კი მათი არსებობა და შიგთავსი მოწმდება.

## ფაილები

- `index.php` — 12-ივე სავარჯიშოს ბმული
- `ex1.php` … `ex12.php` — თითო სავარჯიშო თითო ფაილში
- `style.css` — საერთო სტილი

## გაშვება

```
php -S localhost:8000
```

შემდეგ ბრაუზერში გახსენი `http://localhost:8000/`.

XAMPP-ით: ჩააკოპირე საქაღალდე `C:\xampp\htdocs\`-ში, ჩართე Apache და გახსენი `http://localhost/<საქაღალდის სახელი>/`.
